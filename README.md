🟦 [ 📱 ABOUT THE PROJECT ]

Motivational App is a modern Android application designed to provide users with daily motivation, inspirational thoughts, positive messages, and an engaging visual experience.

The application is developed using Kotlin 100% with Android Studio and includes a custom 3D animated logo and 3D animation effects.
